# homebrew-tap

Homebrew formulae for [alikimovich](https://github.com/alikimovich)'s tools.

```sh
brew install alikimovich/tap/transcriber
```

| Formula | What it is |
| --- | --- |
| [`transcriber`](Formula/transcriber.rb) | Records and transcribes conversations on-device — mic + system audio. [Repo.](https://github.com/alikimovich/transcriber) |

Formulae point at notarized binaries from each project's GitHub Releases and
are updated automatically by the projects' release scripts.
